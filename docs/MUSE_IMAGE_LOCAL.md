# Muse Image illustrations and Picks reveal

The existing real-menu Picks page now shows a full-screen reveal while a **fresh** recommendation request is pending. It uses the saved Taste DNA and the actual extracted menu; it does not display a fictitious progress percentage or make a second inference request. Cached Picks open directly. An offline fixture is explicitly labeled offline.

Primary Picks can display optional Muse Image 1.0 illustrations. The server generates at most three images, each from the validated dish name and menu description, after a successful real Muse Spark result. Generated WebP files and a guest-scoped SQLite cache live in `api/.local/real_picks/`; the existing `.gitignore` excludes them. The private image endpoint requires the guest's Supabase access token. The UI labels every image **AI illustration, not restaurant photography**, and shows a typographic placeholder if no image is available. A failed or interrupted image attempt is not silently retried.

Image dispatch is **off by default**. `MODEL_API_KEY` alone never enables it. After separate owner approval, configure the backend-only `DINETUNED_MUSE_IMAGE_ENABLED=true`, a unique `DINETUNED_MUSE_IMAGE_APPROVAL_ID` (16–80 alphanumeric, `_` or `-` characters), `DINETUNED_MUSE_IMAGE_CAP_USD`, and `DINETUNED_MUSE_IMAGE_MAX_IMAGES`. For one three-image review, set the cap to `0.03` and maximum to `3`. Do not set these in the browser or Vercel. The same locked, persistent local ledger and cumulative $10 development target apply to text and image calls. Official published pricing is $0.01 per image, so the estimated maximum for three is $0.03. Local accounting is **not** a Meta-enforced billing cap; check the Meta dashboard. The price verification window in `usage_budget.py` must still be current before live use. The model is `muse-image-1.0` on `https://api.meta.ai/v1/images/generations`, with one WebP image per request, no tools and no automatic retries.

Illustrations are optional: disabling them leaves real Picks, TasteBridge, meal combinations, refinements and feedback available. Old cached Picks without image records keep their placeholder and require no new Muse Spark call. This milestone makes no claim that images have already been generated for the previous one-shot result.

Official API references: [image generation](https://dev.meta.ai/docs/image-generation), [pricing](https://dev.meta.ai/docs/pricing-rate-limits).
